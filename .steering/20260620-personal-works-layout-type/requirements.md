# Requirements: Personal Works レイアウトのtype対応

## 変更・追加する機能の説明

Personal Works セクションの詳細表示（`PersonalWorkDetail`）を、作品の種別（スマホアプリ／PCウェブ）に応じて画像サイズを切り替えられるようにする。
現状はスマホ向けの縦長レイアウト（`aspect-[9/19]`, `w-48 md:w-56`）にハードコードされており、PC向けのランドスケープなスクリーンショットには対応できていない。

## ユーザーストーリー

- ポートフォリオの閲覧者として、スマホアプリは縦長比率で、Webアプリはワイド比率でスクリーンショットを見たい
- ポートフォリオの閲覧者として、どちらの種別も「左：画像 / 右：説明」という一貫したレイアウトで見たい

## 受け入れ条件

- [ ] `PersonalWork` 型に `type: "mobile" | "web"` フィールドが追加されている
- [ ] `personal-works.json` の各エントリに `type` が設定されている
- [ ] `type: "mobile"` の作品はこれまで通り縦長（`aspect-[9/19]`, `w-48 md:w-56`）で表示される
- [ ] `type: "web"` の作品は横長（`aspect-video`, `w-64 md:w-80`）で表示される
- [ ] どちらの種別も「左：画像 / 右：説明」の2カラムレイアウトを維持する
- [ ] モバイル表示では縦積み（画像上、情報下）へのフォールバックが維持される

## 制約事項

- 変更対象は `types/personal-work.ts`、`data/personal-works.json`、`PersonalWorkDetail.tsx` のみ
- 2カラムレイアウト自体の構造は変更しない
- 既存の Tailwind CSS クラス・デザインシステムに従う
