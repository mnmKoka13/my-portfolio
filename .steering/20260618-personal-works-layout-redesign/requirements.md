# Requirements: Personal Works セクション レイアウト改善

## 変更・追加する機能の説明

Personal Works セクションの詳細表示（`PersonalWorkDetail`）のレイアウトを改善する。
現在はスクリーンショットが横幅フルで上部に表示され、その下にテキスト情報が並ぶ縦積みのレイアウトになっている。
対象アプリがスマホアプリであるため、縦長（ポートレート）の画面比率でスクリーンショットを表示し、右側にアプリの説明情報を配置する2カラムレイアウトに変更する。

## ユーザーストーリー

- ポートフォリオの閲覧者として、スマホアプリのスクリーンショットをアプリらしい縦長の比率で見たい
- ポートフォリオの閲覧者として、画像と説明文を同時に見比べながらアプリの内容を把握したい

## 受け入れ条件

- [ ] 詳細エリアが「左：スクリーンショット」「右：説明情報」の2カラムレイアウトになっている
- [ ] スクリーンショットがスマホ画面比率（縦長、約9:19）で表示される
- [ ] 複数画像がある場合のカルーセル機能が引き続き動作する
- [ ] モバイル表示では縦積み（画像上、情報下）に自然にフォールバックする
- [ ] Overview / Status / Tech Stack / Links の情報は引き続きすべて表示される

## 制約事項

- 変更対象は `PersonalWorkDetail.tsx` と `ImageCarousel.tsx` のみ
- `PersonalWorksSection.tsx` のカード選択ロジックには手を加えない
- 既存の Tailwind CSS クラス・デザインシステムに従う
